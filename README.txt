■ 올리는 법
  1) vercel.com 접속  ※ 학교망에서는 vercel.com 이 막혀 있습니다.
                        집이나 휴대폰 테더링으로 하세요.
  2) Add New… → Project → 이 폴더(vercel-kalimba)를 통째로 끌어다 놓기
  3) 프로젝트 이름은 kalimba 처럼 짓기 → 주소가 kalimba-....vercel.app 이 됩니다
  4) Settings → Deployment Protection → Vercel Authentication → Disabled 로 끄기
     (끄지 않으면 접속할 때 vercel.com 으로 넘어가는데 학교망에서 안 열립니다)
  5) 만들어진 주소를 클래스룸이나 학교 홈페이지에 붙여 넣으면 끝

■ 음원·악보가 들어간 전체 버전은 공개하지 말고 클래스룸에만 첨부하세요
